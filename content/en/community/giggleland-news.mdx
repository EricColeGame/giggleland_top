### How to File a Bug Report That Actually Gets Fixed

If you hit a hardlock, a vague "game broken" post helps nobody. Do this instead:

- Note the exact chapter, room, and interaction that triggered it — "garden nursery keyhole" is a perfect example of a useful report.
- Describe what still works. "The game didn't freeze, but no buttons responded" tells a developer far more than "it crashed."
- Confirm your hardware and whether you've verified your game files through Steam.
- Post it in the community hub with a clear title so other players can confirm the same issue.
- Bump the thread if it recurs rather than starting duplicates — repetition across threads is harder to track.

Multiple confirmations of the same bug in one thread is the fastest way to get it onto a developer's radar.
